# 미니게임 천국 · Mini Game Party

2~6명이 같은 방에서 **바닥이 사라진다**, **밀어내기**, **라이어 게임**을 즐기는 실시간 파티 게임입니다. 회원가입 없이 6자리 숫자 코드로 참가합니다.

## 실행하기

Node.js 22.18 이상이 필요합니다. 프로젝트 폴더에서 실행하세요.

```powershell
npm.cmd ci
npm.cmd run dev
```

호스트는 `http://localhost:3000`을 엽니다. 같은 Wi-Fi의 친구는 `http://호스트의-IPv4-주소:3000`에 접속합니다. Windows에서는 `ipconfig`의 Wi-Fi IPv4 주소를 확인하세요. 게임하는 동안 서버를 실행해 두세요.

## 플레이 순서

1. 방장이 **새로운 방 만들기**를 누릅니다. 친구는 다른 닉네임과 캐릭터 색상을 고르고 **코드로 입장**합니다.
2. 방장이 **대기실의 게임 선택**에서 게임 카드를 누르면 선택한 게임만 반복합니다. 여러 게임을 체크하면 **랜덤 진행**(기본) 또는 **번갈아 진행**으로 즐길 수 있습니다. 선택은 방 안의 모든 화면에 표시됩니다.
3. 3·5·10라운드와 기술 사용 여부를 정합니다. 설정이나 참가자가 바뀌면 준비를 다시 확인합니다. **방장도 준비 완료**를 누르고, 모두 준비되면 **게임 시작**을 누릅니다.
4. 매 라운드에 규칙을 3초간 안내하고 3초 카운트다운 후 시작합니다. 결과를 5초간 보여준 뒤 다음 게임으로 넘어갑니다. 마지막에는 누적 점수와 라운드별 기록을 볼 수 있습니다.
5. 혼자 테스트할 때는 메인 화면의 **바닥이 사라진다 연습**, **밀어내기 연습**, **라이어 게임 연습** 중 하나를 누르면 봇 5명이 참가합니다.

| 조작 | 바닥이 사라진다 | 밀어내기 |
|---|---|---|
| WASD / 방향키 | 이동 | 이동 |
| Space | 점프 · 재사용 3초 | 전방의 가장 가까운 상대 밀치기 · 2초 |
| Shift | 대시 · 4초 | 대시 및 충돌 밀침 · 4초 |
| E | — | 방어 · 5초 |

모바일에서는 왼쪽 조이스틱과 오른쪽 기술 버튼을 사용합니다.

**바닥이 사라진다**에서는 출발 발판도 시작 직후 무너지기 시작합니다. 멈추지 말고 안전한 파란 발판으로 이동하세요. 21×21 경기장의 외곽은 30초부터 줄어듭니다. 두 창으로 두 명을 시험할 때 한 캐릭터만 움직이면 다른 캐릭터가 약 1초 만에 떨어져 라운드가 끝납니다.

**밀어내기**에서는 처음부터 원 안에서 자유롭게 움직일 수 있습니다. 상대를 바라보고 밀치거나 대시로 충돌하세요. 방어는 0.7초간 받는 넉백을 70% 줄입니다. 점선은 3초 뒤 적용되는 다음 안전 반경입니다.

라운드 점수는 실제 참가 인원에서 순위를 빼고 1을 더합니다. 같은 틱에 탈락하거나 90초까지 함께 생존하면 해당 순위 구간의 평균 점수를 받습니다. 최종 동점이면 라운드 1위 횟수로 비교합니다. 경기 중 연결이 끊어지면 같은 탭에서 10초 안에 복구할 수 있고, 유예 중에도 물리 판정은 계속됩니다. 경기 포기자는 남은 점수가 0이며 최종 우승에서 제외됩니다. 남은 참가자가 한 명이면 대기실로 돌아갑니다.

### 라이어 게임 (3~6명)

시민에게 같은 제시어를, 라이어 한 명에게는 주제만 개인 화면으로 보냅니다. 5초간 역할을 확인하고 무작위 순서로 한 번씩 설명하세요. 설명은 12초, 최대 80자입니다. 단어 자체나 초성·번역·글자 수로 정답을 알려주면 안 됩니다.

설명이 끝나면 5초간 다시 읽고 15초 안에 비밀 투표를 확정합니다. 동률이면 해당 후보만 놓고 한 번 더 투표합니다. 라이어가 지목되면 12초 안에 제시어를 맞혀 역전할 수 있습니다. 결과에서 역할, 정답, 각 표와 점수를 공개합니다. 라이어 라운드는 최대 132초이며, 일반 게임의 90초 상한과 구별됩니다.

제시어 105개와 허용 별칭은 서버에서 관리합니다. 같은 매치에서는 제시어를 재사용하지 않습니다. 2인 방에서는 액션 게임만 진행할 수 있고, 혼자서는 라이어 연습 카드를 선택해 봇과 플레이할 수 있습니다.

## 운영과 테스트

프로덕션은 단일 Node.js 프로세스에서 정적 파일과 Socket.IO를 함께 제공합니다. 방과 점수는 메모리에 저장됩니다. 외부 접속용 호스팅에는 HTTPS와 지속적인 WebSocket 연결이 필요합니다.

```sh
npm ci
npm run build
npm start
```

- `PORT`는 서버 포트이며 기본값은 3000입니다.
- 기본 클라이언트는 같은 출처의 서버에 연결합니다. 프론트를 별도로 배포할 때는 빌드 시 `VITE_GAME_SERVER_URL`에 서버의 HTTPS 주소를 설정하고 서버의 `CLIENT_ORIGINS`에 허용할 프론트 출처를 쉼표로 구분해 지정합니다.
- `/health`에서 실행 상태와 게임 버전을 확인할 수 있습니다.

```sh
npm test
npm run build
npx playwright install chromium
npx playwright test
```

Vitest는 선택 순서, 준비 초기화, 발판과 원형 경기장 물리, 공동 순위, 포기 및 재접속을 검사합니다. Playwright는 독립된 세션 6개의 연속 경기, 대기실 단일 게임 선택과 모바일 기술 입력을 검사합니다. 설치된 Chrome을 쓰려면 PowerShell에서 `$env:PW_BROWSER_CHANNEL='chrome'`을 설정하세요.

React·Vite·Phaser 클라이언트와 Node.js·Express·Socket.IO 서버를 사용합니다. 서버는 약 30Hz로 판정하고 약 15Hz로 상태를 전송합니다. 공통 매치 진행과 순위는 `server/game.ts`, 개별 규칙은 `server/games/`, 공유 타입과 게임 목록은 `shared/`에 있습니다. v1의 추가 맵, 아이템, 특수 발판은 후속 확장 범위입니다.
