# 폴링 플로어 (Falling Floor)

밟은 발판이 1초 뒤 사라지는 2~5인 실시간 웹 생존 게임입니다. 친구끼리 6자리 방 코드를 공유해서 플레이하거나, 연습 모드에서 봇 4명과 바로 시작할 수 있습니다.

## 실행

Node.js 22 이상과 npm을 준비한 뒤 프로젝트 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 같은 Wi-Fi의 다른 기기에서는 호스트 컴퓨터의 LAN IP와 포트로 접속합니다. 방을 만든 뒤 6자리 코드를 공유하고, 참가자가 모두 준비하면 방장이 게임을 시작합니다. 서버 재시작 시 메모리에 저장한 방과 점수는 초기화됩니다.

외부에서 접속하려면 WebSocket을 지원하는 Node.js 호스팅에서 한 개의 서버 인스턴스를 실행합니다. 호스팅에서 제공한 `PORT` 값을 사용하며 기본 포트는 3000입니다. 프런트엔드와 게임 서버가 같은 주소를 사용합니다.

```sh
npm ci
npm run build
npm start
```

## 조작과 게임 규칙

- WASD 또는 방향키로 이동합니다. 모바일에서는 왼쪽 조이스틱을 사용합니다.
- Space로 최대 두 발판 중심 거리만큼 점프합니다. Shift 대시는 지상 이동으로 빈칸에서 추락합니다. 재사용 시간은 각각 3초와 4초입니다.
- 3초 카운트다운 뒤 시작 발판도 무너집니다. 기본 발판은 파랑 → 노랑(균열) → 빨강(위험) → 빈칸 순서로 바뀝니다.
- 탈락하면 남은 경기를 관전합니다. 30초부터 외곽에 경고가 나타난 후 발판이 한 겹씩 사라집니다. 90초 이후에는 축소가 빨라집니다.
- 순위 점수는 참가 인원에서 순위를 뺀 뒤 1을 더해 계산합니다. 같은 틱에 탈락하면 해당 순위 구간 점수의 평균을 받습니다. 최종 동점은 라운드 1위 횟수로 비교하고, 이 값도 같으면 공동 우승입니다.
- 방장은 인원, 3·5·10라운드, 맵, 난이도, 붕괴 시간과 액션을 설정할 수 있습니다. 기본 맵은 21×21 정사각형입니다. 십자가·도넛·섬·랜덤 맵도 제공합니다.
- 아이템과 특수 발판은 기본으로 꺼져 있습니다. 아이템을 켜면 15초부터 5초마다 안전 발판에 상자가 등장합니다. 하나씩 보유하고 E 또는 모바일 아이템 버튼으로 사용합니다.
- 노란 상자에서 슈퍼 점프, 폭탄, 밀치기, 얼리기, 보호막, 유령, 위치 교환을 얻습니다. 밀치기와 얼리기는 근처 상대를 조준하며, 짧은 경고 시간에 위치를 벗어나면 피할 수 있습니다. 폭탄은 바라보는 방향 앞쪽을 겨냥합니다.
- 특수 발판은 중앙의 마름모로 표시합니다. 가속(초록), 폭탄(빨강), 얼음(하늘), 강화(남색), 순간이동(보라), 복구(청록)가 있습니다.
- 브라우저 새로고침 또는 일시적인 연결 끊김은 같은 탭에서 5초 안에 재접속할 수 있습니다. 유예 중에도 경기 판정은 계속됩니다.

## 구성과 검증

React·TypeScript가 화면을 구성하고 Phaser가 경기장을 그립니다. Node.js·Express 서버가 방별로 30Hz 시뮬레이션을 실행해 Socket.IO로 초당 약 15회 상태를 전송합니다. 캐릭터, 타일, 로고는 코드로 그린 픽셀 아트입니다.

```sh
npm test
npm run build
npx playwright install chromium
npx playwright test
```

게임 규칙 테스트와 5인 Socket.IO 통합 테스트, 다섯 독립 브라우저 세션의 3라운드 경기, 모바일 크기에서 터치 조작 및 새로고침 복구를 검사합니다. 설치된 Google Chrome으로 브라우저 테스트를 실행하려면 환경 변수 `PW_BROWSER_CHANNEL=chrome`을 설정합니다. 브라우저 테스트는 빌드 결과물을 사용합니다.

다층 생존, 용암, 탈락자가 직접 개입하는 유령의 복수 모드는 기획서의 후속 콘텐츠입니다. 현재 버전은 기본 생존 개인전과 봇 연습전을 제공합니다.
